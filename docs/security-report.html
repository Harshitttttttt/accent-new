What’s clean

SQL injection: safe in both repos (mysql2 placeholders / Drizzle parameterization).
Secrets: clean — .env / .dev.vars gitignored, no hardcoded keys; webhook uses timingSafeEqual via SHA-256.
Money: excellent — Decimal.js + paise integers, Indian grouping, GST helpers (new precision 28).
Uploads (old): sharp rasterization with limitInputPixels:40M neutralizes SVG polyglots; /uploads served with nosniff + attachment.
Scrypt + CSRF (new): N=16384 r=8 p=1, base64url tokens, createCsrfMiddleware on all serverFn.
